VeriSight AI: Eliminating LLM Math Hallucinations in CSV Data

Tool-Assisted, 4-Stage Chained Prompt Architecture with Closed-Loop Self-Verification | Problem ID: C21

⚠️ The Core Challenge: LLM Math Blindness

Foundation models predict next-tokens statistically. When fed tabular CSV dumps, they do mental math: hallucinating averages, inventing correlations, and missing critical anomalies.

❌ Naive Prompting: Raw 35 rows → LLM guesses average revenue: $340.50
✓ Ground Truth: True average is $920.18 (due to $18,750 bulk outlier!)
💡 Our Solution: VeriSight AI (C21)

A tool-assisted pipeline that decouples calculation from writing: a deterministic Python profiler calculates ground truth, feeding into a 4-stage chained prompt engine with closed-loop verification.

🎯 Primary Target: Students, Junior Data Analysts, Non-Technical Managers
🔒 Guarantee: 100% Numerical Faithfulness (Zero Arithmetic Hallucination)

🔍 Stage 4: Closed-Loop Verification (Core C21 Mandate)

Stage 4 acts as an adversarial fact-checker: it parses every numerical claim, percentage, and currency token in Stage 2's prose, cross-referencing it against Stage 0's ground truth. If any hallucination or drift is found, it autonomously triggers self-correction before report presentation.

🛡️ Responsible AI & Ethical Guardrails

• Pre-LLM PII Sanitization: Regex scanner redacts emails, phone numbers, and identity IDs before tokens hit the LLM.
• Sample Size Warnings: Triggers automated advisory when sample size N < 30.
• Verification Badges: Displays auditable 100% verified ledger in UI.

Stage 3 generates Grammar of Graphics chart specifications. And Stage 4—our adversarial fact-checker—audits every single number against ground truth, guaranteeing an airtight audit trail."
